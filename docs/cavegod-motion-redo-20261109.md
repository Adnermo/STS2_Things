# 活体巨岩动作重做 · 1.25.26

用户反馈活体巨岩的骨骼动画「生硬死板」，要求整套重做。本次重做了全部 45 段游戏内动作，新增 4 段抓握循环，共 49 段。打击帧、动作时长、事件、手臂锚点和玩法数值不变；骨架和贴图沿用原素材。

## 重做前的问题

先在原生 Spine 中按实战两层结构（身体在平台后、手臂在平台前）渲染旧动作，逐段检查：

1. **躯干几乎不动。** 攻击时身体、头部、晶冠和胡须基本静止，像一尊石像挂着两条会动的手臂；待机只有几个像素的起伏。
2. **举臂越出画面。** 双掌拍地、双拳锤砸、偷牌、抓取、横扫和倒伏反击的蓄力都把肘部抬到画面顶边之外，前臂从画外垂下。
3. **节奏平均。** 缺少预备、加速、命中硬停和回弹，回收是匀速收回。
4. **愤怒形态逐帧相同。** 除颜色外，愤怒版和普通版的骨骼动画完全一致。
5. **变身与演出对不上。** 11.2 秒的 `main_angry` 基本只是换色；控制器在 4.60／5.33／7.00 秒安排的点燃、咆哮岩爆和砸地震屏，身体上都没有对应动作。
6. **抓握冻结、受击拉扯。** 抓住玩家后把 `grab_player` 冻结在 2.60 秒；`hit_recoil` 以 0.38 权重替换姿态，会把正在出拳的手臂往静止姿态拉。
7. **网格翻折。** 手腕角度常超出前臂／手掌网格的容许范围：32 段动作出现三角形翻折（按 1/30 秒采样共 156 处）。
8. **文件臃肿。** 全部动作以 120 Hz 逐帧烘焙，`cave_god.spjson` 有 41 MB。

## 动作语言

- **全身发力。** 每次出手：预备（下沉或后拧）→ 身体先行 → 手臂加速 → 命中硬停 → 0.1–0.2 秒压住 → 回弹落定。头部以二阶跟随滞后于躯干，胡须是受下巴加速度驱动的单摆，命中时晶冠、角与肩膀有衰减震颤。
- **正面机位的举臂规则。** 肩膀接近画面顶边。拳头抬起时在肩膀内侧上升，肘部朝外下垂，形成蓄力的折臂；拳头在肩外侧时保持低位或接近伸直。生成器会报告肘部出画或前臂悬垂。
- **手腕弯折。** 手按相对前臂的向内弯折编排，并限制在两侧网格都不翻折的 −8°～38°；拳击时指节领先，拍地时掌面压平。
- **手型。** 张掌（`arm*_3_2`）与握拳（`arm*_3`）按节拍切换：出拳前握紧，拍地保持张掌，偷牌在 1.60 秒合掌。
- **愤怒形态。** 身体压低 10、头前探、双肩耸起内收、角张开 7%、拳头更紧；每次出手前半秒有压抑的颤抖，命中震动加重 30%。愤怒待机改为每 2 秒一次粗重呼吸并持续颤抖。
- **循环。** 待机、倒伏和抓握循环的所有波形按周期整除，首尾逐帧相同。

## 代码与工具改动

- `NCaveGodBossBackground.HoldGrabAnim` 改为以 0.35 秒混合进入 `grab_hold[_right][_angry]` 循环，不再冻结 `grab_player` 的 2.60 秒；`ResumeSlamAnim` 以 0.15 秒混合吸收循环相位，原来是 0 秒硬接。
- `RestoreCapturedPlayersInstantly` 把所有 `grab_` 片段视为携带俘虏的动作，包括新的抓握循环。
- `SetHurtTrackAnimationBoth` 以 Spine MixBlend.add、权重 1 播放 `hit_recoil`；动画只存相对静止姿态的增量，肩膀保持世界位置。
- `scripts/build_cavegod_contact.mjs` 默认读取新的动作基准；已经回到待机的片段不再强行收尾；120 Hz 辅助键按误差精简，输出紧凑 JSON。重新生成了 `CaveGodContactProfiles.cs` 与 `contact_profiles.json`。
- `scripts/pack-resource-overrides.gd` 的覆盖白名单增加 `animations/*.spjson`，用于只替换骨骼文件的打包。
- 新增维护源 [`tools/CaveGodRig`](../tools/CaveGodRig/README.md)；旧的右手烘焙与偷牌生成流程见 [`source_assets/monsters/cave_god_motion`](../source_assets/monsters/cave_god_motion/README.md) 的说明，已被取代。
- 版本号改为 1.25.26。`CaveGodAnimTiming`、Spine 事件和所有玩法代码不变。

## 限制

- 预览和检查都是 Godot 原生 Spine 离屏渲染与探针，没有在真实游戏里实战观看，也没有多机联机。
- 右臂被击倒后的伏地姿势中，右拳网格仍有一个小三角翻折，涉及 5 段右侧／愤怒倒伏动作；调整手腕弯折无法消除，旧版同样存在。
- 全项目审计报告 `manifests/v107.1`、`manifests/v111` 两份诊断清单仍是 1.25.17。HEAD 上已是如此，本次没有改动它们；统一包使用根目录清单。
- 工作区中其他未完成的改动（Soul Roes）没有进入本次构建：DLL 由 HEAD `fc9f17f` 加上本次文件的独立快照编译，PCK 由 1.25.25 发布 PCK 只替换 `cave_god.spjson` 得到。
- 未安装到本机游戏，未发布到创意工坊或 GitHub。
