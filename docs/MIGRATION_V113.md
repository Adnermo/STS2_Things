## 游戏侧主要变化

1. **Fool 内容链。** 原版 AllCharacters 由五个扩至六个，加入 Fool 及专属卡牌、药水、遗物池；包含箭矢、旋律、塔罗相关类型。另有 RotatingCharacter 供轮换玩法，不把它计作另一个正式角色。
2. **模式与进阶。** GameMode 新增 Dread / Blitz，Custom 从枚举拆成 `IsCustomGame`；开局接口新增 bool，AscensionManager 按模式构造。新增 Blitz 商店、地图/模式选择和 RunModel 链路。
3. **商店同步重构。** 原生购买改由 MerchantSynchronizer 广播、各端确定性结算，库存条目增加 ID 和购买生命周期；普通/Blitz 商店场景拆分。
4. **战斗结算与 UI。** AfterDeath 新增卡牌来源；LoseMaxHp 使用 cardSource；多段攻击次数使用 HitCountVar；怪物交互、血条与意图显示改由新的原生状态显示流程控制。
5. **生成、选牌、保存与诊断。** ActModel 新增 GenerateRooms 包装重载；选牌改为按玩家的 CardSelectorStack；新增 RunModel 生命周期；F2 截图/附件与顶部 UI 调整。当前原生 schema 为 Progress 24、RunHistory 11、Run 21、Settings 8。

## 模组迁移

开发版本升为 **1.25.27**，活动目标变为 **107.1 + 113**，统一 manifest 最低游戏版本保持 `v0.107.1`。v111 诊断 manifest 退出活动目录，历史产物保留。详见 [双版本合同](DUAL_VERSION_SUPPORT.md)。

- 条件编译适配全部死亡覆写、父类调用与生命上限损失，不修改事件和怪物数值。
- 巨岩动态交互走新版 `SetIsInteractable`；静态 IsInteractable 属性不承载阶段变化。释放玩家后调用原生状态显示动画。
- 精确选择 GenerateRooms 的实际生成重载；保留深处事件池与遭遇抽选规则。
- 商人猜拳在原生购买广播前执行，协商价格走原生可靠位置缓冲，先价格、后原生购买、结算后清理；个人库存和奖励由原版结算。
- 配置同步适配 StartRunLobby/JoinFlow 新构造签名；F2 只对本 Mod 明确选择的类别使用新版附件接口。
- **分裂适配 HitCountVar**，仍采用原规则取整；旧 SplitState 的 Repeat 字段在目标卡已经切到 HitCount 时窄迁移，保留已有成长与可见数值，不修改另有 Repeat 的卡。
- 构建参数、探针默认目标、源码门禁与文档更新为 v113；探针中的原生开局/进阶/选牌/RunModel 差异集中在测试适配器，不加入运行包。
- 运行包保留 1.25.26 的共用资源，PCK SHA256 仍为 `99ed58dcdbf2da3e2fff940916afdb4b0d4d8386af3a1a66ab337adc07e7b0c2`。

原有 Soul Roes 生命/死亡召唤 WIP 留在工作区；本次运行 DLL 从排除该 WIP 的独立源码快照构建。其死亡签名的兼容适配保留，但未纳入未完成玩法改动。
