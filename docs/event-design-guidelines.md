# 自制事件设计规范

用户约定：普通事件一般以小额纯增益代替空白「离开」；2026-10-06 补充，无损选项按主题设计，不统一奖励 15 金币。

- 为自制普通事件提供符合主题、无需付出资源的小收益选项，例如少量回复、免费药水或少量金币。收益量结合所在章节和其他选项决定；`DepthsEventDefaults` 中的 15 金币仅供适合给钱的分支使用。
- 已有免费奖励分支时，可直接将其作为无损选择，无需再加一项通用奖励。检查获得限制；例如无法获得药水时，提供主题相符的替代收益，并锁定无法兑现的交易。
- 分支结算后的「继续」「结束」用于结束已经结算的流程，不再重复奖励。取消选牌应返回选择页面，不以空结局替代收益选项。
- 选项独立清楚，玩家直接看见代价与所得；风险和战斗在选择前写明。洞胃四种喂食直接展开，再提供小收益选择。
- 原版事件文风：第二人称、具体动作、短对白与简短反应；效果说明直接写「移除……。获得……。」。参考当前原版事件表，不用模糊隐喻替代动作和效果。
- 多人先确定选择是否共享。个人交易只改变各自资源；切换战斗使用原版共享事件同步；休息点各自结算，用原版选项协议完成房间。
- 用原生存档属性保存跨房间收益与代价，保留领取标记，处理重复载入、死亡延迟和跨章节情况。
- 每次调整后审查所有可选路径：有合法选择、没有重复领取、没有仅因为缺少资源而卡住；查看中英文与多人排版。验证方式遵守当前用户授权。

## 事件遭遇门槛（`IsAllowed`）标准（2026-11-21 对齐原版确立）

所有自制事件在进入房间前必须按原版《杀戮尖塔 2》的遭遇门槛设计重写 `IsAllowed(IRunState runState)`，避免出现“核心卖点全锁、满血进纯病房、开局过早撞牌组折磨、或多人共享投票送死残血队友”等无效房间体验：

1. **全员一致性（`Players.All`）**：非单人特例下，资源、血量、卡组目标与遗物/药水门槛必须使用 `runState.Players.Count > 0 && runState.Players.All(player => !player.Creature.IsDead && ...)`（与原版 `MorphicGrove`、`CrystalSphere`、`RelicTrader`、`SpiralingWhirlpool` 一致），防止联机局仅一人达标而其余队友进房全锁。
2. **金币消费／倾家荡产事件必卡金币下限**：
   - 全选项付费或核心选项要求清空／大额金币的事件（如《虚荣天平》3 层 `Gold >= 250`、《蚌口夹珍》`Gold >= 45`、高额消费服务事件），必须在 `IsAllowed` 中要求金币达到主选项门槛（如“清空全部金币”类事件与选项最低门槛保持同一数值），杜绝没钱吃闭门羹或 3 层低价白嫖。
3. **卖血／强制扣血与纯回血事件必卡血量边界**：
   - 核心玩法全需扣血或连“拒绝/离开”都会扣血的事件，要求 `CurrentHp > 最低扣血值`（如《古林落籽盘》`> 16`、《过饱育婴室》`> 9 && MaxHp > 10`、《墙缝账房》`> 8`）；
   - 多人共享投票事件（`IsShared => true`）若存在全员扣血分支（如《谁去推门》全员 `-12`），必须对标原版 `DenseVegetation` 要求全员 `CurrentHp > 全员扣血值`，防止投票直接送走残血队友；
   - **纯回血事件**（所有选项均为回血，如《满员的病房》）对标原版 `UnrestSite` 反向卡血量上限（`CurrentHp <= MaxHp * 0.75m`），避免满血白逛。
4. **特定遗物／药水／卡牌／附魔事件必卡合法目标与防重复**：
   - 需要交易/典当遗物或消耗药水的事件，要求持有对应合法遗物/药水（如《墙缝账房》至少持有 1 件可交易罕见/稀有遗物、《遗物修补摊》至少持有 1 件可交易遗物）；
   - 以特定附魔、删牌、变化或同名合并为核心卖点的事件，对标原版 `SpiralingWhirlpool` / `FieldOfManSizedHoles` / `WoodCarvings`，要求牌库内存在至少 1 组满足该核心选项的合法目标牌（存在双主线时可采用“至少满足一条主线”的逻辑）；
   - 发放唯一专属事件遗物或跨房契约（如《发烫的蜡封匣》《影子寄存处》《菌根借贷所》《温热的育王巢房》）的事件，必须检查玩家尚未持有该遗物且距当前章节 Boss 尚有足够房间。
5. **前期高折磨事件必卡层数（`TotalFloor`）**：
   - 像《借牌老藤》这类对标原版 `SlipperyBridge`、直接点名移除/递增掉血折磨牌组的 1 层事件，须卡最低层数（如 `TotalFloor >= 5`）与最低血量，避开开局前几格只有基础牌的极端局面。

此约定适用于自制事件，当前同步到深处事件。原版事件池中的原作事件保持其原有选择。
