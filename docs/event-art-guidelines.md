# 事件插画：原版无黑线手绘色块、紧凑微缩主体与场景纯色剪影过渡规范

2026-11-26 `v0.114.0` 升级更新：结合原版《杀戮尖塔 2》（*Slay the Spire 2*）`v0.114.0` 最新实装事件（如拇指夹事件 `museum_of_torture.png` / `_02.png` / `_03.png`，以及 `wood_carvings`、`stone_of_all_time`、`self_help_book`、`byrdonis_nest`、`sunken_statue`、`tea_master`、`the_legends_were_true` 等全量原版事件）的量化测绘与本模组全部 37 张事件实机对齐验证，确立当前事件插画统一制作基准：

## 核心画风与构图铁律

1. **无黑线勾边的不透明手绘雕琢块面（Lineless Painted Angular Shapes & Crisp Opaque Value Planes）**：
   - 原版核心事件与本模组全套原生生物均采用**无黑线勾边（Lineless / Edge-to-Edge Opaque Painting）**的 2D 手绘概念块面：石砖、木板、金属、衣褶、菌盖与生物体块完全依靠**明暗色阶对比、冷暖折面转折、硬朗崩角高光（Chipped Bevel Highlights）与深色闭塞缝隙**区分形体，单一材质保持 3~5 阶克制哑光手绘层次。
   - **四大绝对禁区**：
     - 严禁 **Flash／手游式均匀黑线卡通勾边与矢量贴纸描边**（禁用 `"polygonal-lasso + 2-4 flat steps"` 写法）；
     - 严禁 **《暗黑地牢》／美漫墨线排线（Darkest Dungeon / Mike Mignola comic cross-hatching）** 与狰狞写实恐怖肌肉；
     - 严禁 **柔焦喷枪霓虹光晕（blurry airbrush glow）** 与油腻厚涂模糊；
     - 严禁 **3D CGI / Blender 塑料高光与写实摄影噪点**。

2. **紧凑拉远微缩舞台与原版级纯色留白占比（Compact Diorama + Expanded Pure Solid Margins）**：
   - `default_event_layout.tscn` 将 `3440 × 1616` 原画按 `(2662.4, 1248.0)`、偏移 `(-371.2, -79.0)` 贴入 `1920 × 1080` 视口：
     - `16:9` 实际可见窗位于纹理 `x = 13.94%..86.06%, y = 6.33%..92.87%`；
     - 右侧 `%Title`（居中 `x = 1322, y = 236`）、`%EventDescription` 与 `%OptionsContainer` 占据 `x >= 48.6%`（`1671..2820px`）。
   - 经对原版 `v0.114.0` 全量事件测绘，原版主体相当克制且外围纯色底占比极大（原版全幅纯色中位数 `72.9%`、高位段 `78%–92%`；`16:9` 可见窗有效亮部占比中位数仅 **`16.3%`**）。
   - 因此本模组全部事件统一执行以下量化红线（本模组 37 张升级后实测：全幅纯色中位数 `88.1%`、`16:9` 亮部中位数 `16.8%`）：
     - **全幅 `3440 × 1616` 纯色外围占比（`FullSol`）**：**`78%–92%`**（理想值 `84%–90%`）；
     - **`16:9` 可见窗有效受光主体占比（`16:9Act`）**：**`14%–23%`**（理想中位数 `16%–20%`）；
     - **左侧叙事重心与右 UI 零越界**：受光主体中心收束在 `3440 × 1616` 的 **`x = 28%–33%`**（恰好居中于 `16:9` 左侧可视舞台 `[13.94%, 48.6%]`），受光右缘严格停在 **`x <= 47.2%`**，右侧文字与选项按钮区（`x >= 49.5%`）亮部泄漏 **`<= 0.5%`**（优先 `0.00%`）。

3. **场景内纯色剪影物品过渡（In-Scene Solid-Silhouette Foreground Transition — 对齐原版 `museum_of_torture.png`）**：
   - 学习原版 `v0.114.0` 拇指夹事件（`museum_of_torture.png`）用粗犷纯色铁链斜穿前景、自然将紧凑受光场景过渡到外围大片纯色底的手法：每个事件须采用**高度贴合自身题材的前景纯色剪影道具**承接主体与纯色外缘的过渡——例如斜向铁链与滑轮（命悬一线、歪掉的砝码秤、裂纹琉璃火盆）、码头缆绳与木桩海带（盲蟹墨缸、蚌口夹珍）、垂挂电缆与铁管（过载接线亭、记仇的贩卖机）、郊区树冠电线与白栅栏（对齐之屋）、天鹅绒帷幕与立镜框（镀银试衣镜、药水试饮会）、病房拱门与挂环拉帘（满员的病房）、钟乳石与树根（礼貌的洞胃、收音井、借牌老藤）、六边形蜂巢拱肋（兵蚁分拣台、温热的育王巢房）、后室隔断门框与管道（后室）等。
   - **同色融合与零截断线铁律**：所有前景剪影装饰必须与最外围纯色底采用**完全一致的单一深色底 RGB（`bg_rgb`）**，无缝延伸融入外围纯色并贯通画布四边——**严禁前景剪影比外围底色更黑而产生矩形/水平截断线，严禁通用锯齿假山洞钥匙孔黑框、浅色椭圆舞台聚光圈或镜像翻转拼接缝**。

4. **场景匹配参考协议（严禁四宫格拼图 + 严禁克隆圆形石台 + 物种 100% 还原）**：
   - **严禁投喂带分割线的 `2×2` 四宫格拼图参考板**（易诱发分屏与边框伪影）。
   - **严禁将《收音井》（`things_echoing_well.png`）作为非井类事件的默认地形参考**（防止模型把环形石砖地台和背后三立柱克隆进所有事件）。
   - 新建事件时优先传入 `museum_of_torture.png` 作为**紧凑比例 + 场景前景纯色剪影过渡**结构参考，搭配 1 张同地形无圆台的原版单幅事件（如 `wood_carvings.png`、`self_help_book.png`、`tea_master.png`、`the_legends_were_true.png`、`hungry_for_mushrooms.png`、`sunken_statue.png`）；改版/扩图已有事件时，先将原干净主体缩放锁定到 `1920 × 1080`（`16:9`）纯色底图左侧（`x ≈ 13%..50%, y ≈ 18%..82%`）作为图 1，再配对 `museum_of_torture.png` 生成贴合主题的前景剪影过渡。
   - 涉及本模组怪物（逆行蝾螈、菌根双子、洞胃、深处三蜗牛、甲虫匠、人面柱）时，单独传入无白边暗底物种标准参考卡，锁解剖与配色并在场景光影中重绘。

## 制作、确定性扩图打包与交付核验

1. **确定性 `16:9 → 3440 × 1616` 扩图打包流程**：
   - 生图工具最宽比例为 `16:9`，因此母版固定生成 `16:9`（受光主体位于 `x ≈ 5%..58%`，右侧 `x = 60%..100%` 为纯净单一深色底 `bg_rgb`）。
   - 打包脚本按以下步骤确定性合成 `3440 × 1616` RGBA（`Alpha = 255`）：
     1. 采样右侧纯净区中位数 `bg_rgb`；
     2. 对低于 `bg_luma + 10` 的极暗前景剪影像素平滑抬升至精确 `bg_rgb`，并统一外围 JPEG 暗部噪点，确保前景剪影与外围纯色 100% 同色零阶跃；
     3. 按目标亮部面积（`16:9Act ≈ 16%–20%`）等比缩放至 `height_scale ∈ [0.62, 0.88]`，四边施加 `72–96px` 余弦平滑羽化（`smoothstep`）消除任何宽屏贴图边线；
     4. 自动将受光重心对齐至 `x ≈ 30.8%`（右缘严格 `<= 47.2%`），四周用精确 `bg_rgb` 延展补全至 `3440 × 1616`。
2. **双维度视觉验收**：
   - 生成全量总览接触表（叠加青色 `16:9` 视口框与橙色 `x = 48.6%` UI 分界线）逐张目检比例一致性与零接缝；
   - 调用 `scripts/archive/native_event_preview.py`（原版思源宋体／Kreon、真实 `event_button.png`、精确 `DefaultEventLayout` 坐标）抽检 `1920 × 1080` 实机排版，确认零切边、零撞字。
3. **归档与工程校验**：
   - 将原始 `16:9` 母版、`3440 × 1616` 成品、总览图、1080p 抽检图与 `SHA-256` 清单归档至 `source_assets/events_v6_solid_silhouette_20261126/`；
   - 部署后运行 `python scripts/verify_project.py` 确认全部事件资产为精确 `3440 × 1616` RGBA 且零报错。
