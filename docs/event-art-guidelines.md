# 事件插画：原版无黑线手绘色块与全幅连续暗场规范

2026-11-15 重铸更新：经对原版《杀戮尖塔 2》（*Slay the Spire 2*）全部 59 张 `3440 × 1616` 事件插画（`wood_carvings`、`self_help_book`、`byrdonis_nest`、`sunken_statue`、`tea_master`、`this_or_that`、`stone_of_all_time`、`the_legends_were_true`、`room_full_of_cheese`、`doors_of_light_and_dark` 等）与本模组标杆《收音井》（`things_echoing_well.png`）的全幅及 `1:1` 原生像素对比，彻底废除前版误导性的“`c/d` 多边形套索 + 死黑楔块 + `#000000` 假山洞裁切框”规则，确立以下真实原版事件美术基准：

## 核心画风铁律

1. **无黑线勾边的不透明手绘雕琢块面（Lineless Painted Angular Shapes & Crisp Opaque Value Planes）**：
   - 原版核心事件与本模组全套原生生物均采用**无黑线勾边（Lineless / Edge-to-Edge Opaque Painting）**的 2D 手绘概念块面：石砖、木板、金属、衣褶、菌盖与生物体块完全依靠**明暗色阶对比、冷暖折面转折、硬朗崩角高光（Chipped Bevel Highlights）与深色闭塞缝隙**区分形体，单一材质保持 3~5 阶克制哑光手绘层次。
   - **四大绝对禁区**：
     - 严禁 **Flash／手游式均匀黑线卡通勾边与矢量贴纸描边**（前版误写 `"polygonal-lasso + 2-4 flat value steps + zero brush"` 的直接恶果）；
     - 严禁 **《暗黑地牢》／美漫墨线排线（Darkest Dungeon / Mike Mignola comic cross-hatching）** 与狰狞写实恐怖肌肉；
     - 严禁 **柔焦喷枪霓虹光晕（blurry airbrush glow）** 与油腻厚涂模糊；
     - 严禁 **3D CGI / Blender 塑料高光与写实摄影噪点**。

2. **拉远俯视 `3/4` 叙事微缩舞台与视口安全边界（Overscan-Safe Pulled-Back Diorama Scale）**：
   - `default_event_layout.tscn` 将 `3440 × 1616` 原画按 `(2662, 1251)`、偏移 `(-371, -79)` 贴入 `1920 × 1080` 视口，且 `%Title`（居中 `x = 1322, y = 236`）、`%EventDescription` 与 `%OptionsContainer` 全部位于右侧 `x = 922..1722`。
   - 因此在 `16:9` 生成母版中，相机必须对齐《收音井》与 `wood_carvings` 的**拉远俯视 `3/4` 剧场距离**：核心角色／器物与 2~3 件点题道具须完整收束在 **`x = 19%..42%, y = 24%..75%`**（约占画宽 `20%–24%`），左侧 `0%..18%`、顶部 `0%..23%` 与底部 `76%..100%` 留出完整延伸的暗部地面／柱廊余量，确保尾巴、门楣、灯笼、药水瓶在 `2.13:1` 裁切与 `(-371, -79)` 视口过扫下**零切边**。

3. **全幅连续空间与点光源自然衰减（Continuous Unbroken World — 严禁钥匙孔黑框与椭圆聚光圈）**：
   - 整幅 `3440 × 1616` 必须是**同一处连续不断裂的真实空间**：石板、水洼、岩柱、拱廊、墙纸隔断或街道地平线从左至右自然贯通。
   - 照明仅来自左侧叙事焦点的**戏剧性双色温点光源**（如发光井水、炼药铁锅、红种玻璃罐、壁挂油灯、余烬沙漏、火花或天光窄缝），向右半屏（`x = 46%..100%`）自然衰减为**安静、极低对比度的深色有色暗场**（深渊蓝青、暗板岩靛、幽暗苔绿或深褐橄榄，`proseL ≈ 8..35`，隐约可见极暗远景地砖与柱影），**严禁剪刀式垂直切黑洞、严禁套假山洞锯齿框、严禁画浅色椭圆舞台聚光盘**。

4. **场景匹配参考协议（禁止用《收音井》当通用地板模板 + 零多宫格拼图 + 物种 100% 还原）**：
   - **严禁投喂带分割线的 `2×2` 四宫格拼图参考板**（易诱发分屏与边框伪影）。
   - **严禁将 `images/events/things_echoing_well.png` 作为其他非井类事件的默认图 1 参考**：《收音井》包含显著的环形石砖地台、背后立柱与蓝色水洼，若作通用模板会导致多个事件地板千篇一律变成圆形石台。
   - 改为按事件真实题材直接选用无黑框、无圆台的原版单幅事件全图作图 1 + 图 2（**碎石/废墟平地**：`self_help_book.png`、`byrdonis_nest.png`；**室内摊位/柜台/工坊**：`tea_master.png`、`room_full_of_cheese.png`、`welcome_to_wongos.png`；**高塔走廊/机械室**：`the_legends_were_true.png`、`battleworn_dummy.png`；**林地/菌土/营火**：`hungry_for_mushrooms.png`、`wellspring.png`；**浅水/湿地/木栈道**：`sunken_statue.png`、`battleworn_dummy.png`），仅作无黑线质感、镜头距离与连续暗场参考，且禁止生图模型自作主张绘制圆形石台或三根立柱。
   - 涉及本模组怪物（逆行蝾螈、菌根双子、洞胃、深处三蜗牛、甲虫匠、人面柱）时，单独传入**无白边、未经色阶海报化破坏的暗底物种标准参考卡**作为物种解剖、配色斑纹与半耷拉眼神参考，并在新环境光影中重绘为鲜活的 `3/4` 叙事姿态。
