## 原版怪物五大真实美术基准

1. **强制挂载 `1:1` 原生纹理切片（替代只传缩小白底渲染图）**：
   - 生图前从 `sts2-monster-art/resources/swatch_cat*.png` 选取对应 `1–2` 张未缩放原生纹理拼板（提炼自 `STS2-V111/animations/monsters/` 的 `spinytoad`、`waterfall_giant`、`mawler`、`tunneler`、`slumberingbeetle`、`living_shield`、`vine_shambler`、`devoted_sculptor` 等），让生图模型直接锁定 Mega Crit 的真实笔触分辨率、纸张干笔颗粒与皮肤龟裂纹。
2. **轻薄不均匀的本地色勾边 ＋ 扁平干脆暗面（禁止 3D 球体软喷枪渐变）**：
   - 部位转折、岩缝、下颌褶皱与爪趾边保留 **`1–2px` 轻薄、手绘不均的深一号本地色压边**；明暗靠 **2–3 个干脆扁平的水粉暗亮色面** 配合少量干笔矿物飞白与老皮裂纹（`crackle`）塑形，**严禁 3D 球体空气笔柔光过渡**。
3. **死鱼眼与荒诞怪相（禁止皮克斯微笑萌宠）**：
   - 保留重眼皮、大小/高低略不对称的淡奶黄/灰白眼睛与小黑瞳、宽扁歪斜/倔强神态，以及 ~4 头身笨重或怪异比例。
4. **左向 `3/4` 待机与清晰拆骨缝隙**：
   - 面向左侧、四足/双腿落同一水平基线、成图四周留白 `>= 12%`；双腿间、腋下、武器旁留足明确背景空隙以备 Spine 切分，**严禁内置地面投影或底座石块**。
5. **`#00FF00` 默认绿幕（绿色生物用 `#FFFFFF`）＋ `3px` 内向去污**：
   - 非鲜绿/苔绿怪物优先使用 `#00FF00` 纯平绿幕出图（能清晰衬出奶白/浅米色眼口爪边缘且最易触发硬朗 2D 手绘感）；纯绿系生物用 `#FFFFFF` 纯白底。随后统一执行 `sts2-monster-art/scripts/extract_monster_rgba.py` 进行边界泛洪＋`3px` 前景色内向去污与双向实景站队核验。
