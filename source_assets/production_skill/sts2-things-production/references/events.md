# 自制事件规范

修改事件先读项目当前 `docs/event-design-guidelines.md`；插画、留白或排版再读 `docs/event-art-guidelines.md`。它们是项目维护的细则，这里只保留用户的稳定要求与路由。

## 机制、选项与文本

- 事件实用、有趣、能作出有意义的选择，尽量不破坏基础玩法；创意不必都围绕当前怪物。
- **福利必有代价，退路为纯粹离开（2026-11-24 取代旧“无损选项白送小收益”约定）**：自制普通策略事件的每一项正面收益（回血、最大生命、金币、药水、遗物、删牌、升级、变化、附魔等）均须匹配贴合主题的真实代价（血量、最大生命、金币、诅咒、牌/遗物交换或战斗）；不愿付出代价或资源不足时提供纯粹「离开」（无收益），不再白送免费增益。5 款联机小游戏维持各自独立设计。
- 不同代价／牌型的选择独立展示，例如洞胃的攻击、技能、能力、诅咒分别成为直接选项。玩家选之前就看见代价、所得、风险及是否会进入战斗。
- 原版文风是第二人称、具体动作、短对白与短反应；效果明确写“移除……。获得……。”，不过度解释后台机制。
- 奖励结算后的“继续／结束”负责退出流程，不重复发奖。取消选牌回到选择页面；资源不足、药水无法取得等情况有合法路径或主题相符的替代。
- 个人交易、共享战斗和休息点分清归属，使用原生选择同步与 SavedProperty 记录跨房间状态，防止读档、取消或重复点击重复领取。
- **遭遇门槛（`IsAllowed`）与多人安全兜底（2026-11-26 修订）**：所有自制事件须按 `docs/event-design-guidelines.md` 中的最新遭遇门槛标准，统一使用 `runState.Players.Any(player => !player.Creature.IsDead && ...)`（多人专属事件前置 `Players.Count > 1`）按**最低可用主分支**校验金币下限、血量安全线、纯回血反向血量上限、可交易遗物／药水／合法附魔或卡牌目标、唯一专属遗物防重复与距 Boss 房距及前期折磨层数（`TotalFloor`）；不再用严苛的 `Players.All(...)` 封死联机事件池。凡含致死扣血且原无无损退路的事件须为低血量队友提供纯粹 0 伤害「离开」（`LEAVE`）兜底；多人共享投票事件（`IsShared => true`）所有选项的锁态必须全端一致（如《礼貌的洞胃》按全队 `Any` 解锁、未达标队友走 `NO_FOOD` 完结）。

这项“普通事件提供小收益”的约定适用于自制内容，不擅自重写原版事件的离开分支。特定事件的价格或奖励改动不作为全部事件固定预算。

## 事件插画

2026-11-26 `v0.114.0` 升级更新：以项目 `docs/event-art-guidelines.md` 与 `sts2-event-art` 规范为准——全面对齐《杀戮尖塔 2》`v0.114.0` 原版事件（重点含拇指夹事件 `museum_of_torture.png`、`wood_carvings`、`self_help_book`、`tea_master`、`byrdonis_nest`、`sunken_statue` 等）：

1. **无黑线勾边不透明手绘块面（Lineless Painted Angular Shapes & Crisp Opaque Value Planes）**：
   - 石砖、木器、金属、织物与生物完全靠**明暗体块、冷暖折面、硬朗崩角高光与深色闭塞缝隙**塑形，保留略带卡通感的原版比例与克制哑光笔触。
   - **绝对禁止** Flash 卡通粗黑描边、禁止《暗黑地牢》美漫排线、禁止柔焦喷枪霓虹光晕与 3D 塑料感。
2. **紧凑微缩主体 + 大面积纯色外围留白（对齐原版比例）**：
   - `3440 × 1616` 全幅纯色外围占比保持 **`78%–92%`**（目标 `84%–90%`），`16:9` 可见窗有效受光占比保持 **`14%–23%`**（对齐原版中位数 `16.3%`）。
   - 受光主体重心落于 `x = 28%–33%`，受光右缘严格停在 `x <= 47.2%`，右侧标题／正文／选项区（`x >= 48.6%`）保持 100% 均匀纯色无撞字（`UILeak <= 0.5%`）。
3. **场景内纯色剪影物品过渡（学原版 `museum_of_torture.png`）**：
   - 用高度贴合自身题材的前景纯色剪影道具（铁链、缆绳、电缆管道、树枝电线栅栏、天鹅绒幕布、病房挂帘、钟乳石树根、蜂巢拱肋、书架封箱等）自然将紧凑受光场景桥接到外围大片纯色底。
   - 前景剪影须与外围底色严格同色（打包阶段对近黑剪影平滑抬升至 `bg_rgb` 并对 `16:9 → 3440 × 1616` 四边做 `72–96px` 余弦平滑羽化），**严禁水平/竖直截断线、矩形方框边、通用假山洞钥匙孔框、浅色椭圆光圈及左右镜像拼接缝**。
4. **单幅参考解耦与双维原生排版验收**：
   - 拒绝四宫格拼图参考与通用圆形石台克隆（野外/林地类事件勿传带铁链参考，防止串味）；所有成品须经全量总览表（青色 `16:9` 窗 + 橙色 UI 线）与 `scripts/archive/native_event_preview.py` 1080p 原生字体排版核验并归档至 `source_assets/`，最后运行 `scripts/verify_project.py` 验收通过。
