# 美术与生图

## 风格基准

先实际查看同版本、同资源类型的原版图。角色原画、卡面、能力图标、地图模板有不同的简化程度，不能用一套“高细节插画”提示词处理所有资源。

- 角色：略卡通的比例、明确剪影与大块手绘明暗。依生物的设定决定表情和材质，不默认加尖牙、凶相和写实解剖，也不默认加婴儿式大眼；怪物详细规范见项目 `docs/monster-art-guidelines.md` 与 `sts2-monster-art`（`1:1` 原生图集纹理拼板锚定、`1–2px` 轻薄本地色压边＋扁平哑光水粉暗块＋干笔颗粒、死鱼眼微拙比例、`#00FF00`/`#FFFFFF` 内向去污抠像及 Spine 拆骨间隙）。
- 卡面：近黑轮廓或集中阴影、简化的绘画块面，一个清楚的动作／物体焦点。输出纯肖像，由原版组件添加卡框、文字和费用；按实际卡框裁切验收。
- 事件：查看数张原版完整插画，再放大同类主体的亮部和材质细节。原版事件的细节密度不同，不能把画风统一归结为“大色块”或强制两三层平涂；比较具体线条、形体、褶皱、材质笔触与局部明暗，按选定参考组织细节。概念场景的碎色笔触与僵硬的多边形拼面都可能偏离原图。
- Buff 图标：紧凑剪影、粗而略不规则的深色轮廓、少量颜色和高光，在 32／64 px 仍可辨。表现机制主体，控制发光、爆点、细密刻面与装饰底框。
- 迷你物品图案：用物件和动势自然构成用户所需的整体形状；正方形或圆形不是给主体外面套一圈框。简色、少细节、保留物品特征。
- Boss 地图图标：沿用原版的单色模板与描边着色方式；战斗记录头像另按原版彩色缩略图处理。用户明确只要纯黑／纯白时按该次要求，不把它推广为所有彩色图标的规则。

原图已经确定的修复／动画任务，保留原画身份和色系。局部补绘限定在断肢遮挡、透明边缘等实际问题；用户明确要求重绘时才改变对应内容。用户选择保留本体、只重画界面时，按选定资产范围执行。

## 生图方式（不强制绑定 `gpt-image`）

2026-11-15 更新：不再强制要求使用 `gpt-image-2.5-sunburst` 或外部 `imagegen` 接口。默认可使用当前环境内置的 `image-generator` 子代理配合对应资产的专项美术技能（`sts2-monster-art`、`sts2-background-art`、`sts2-card-art`、`sts2-event-art`、`sts2-power-art`、`sts2-curse-art`、`sts2-boss-map-art`）生成与后处理；仅当用户单次明确指定特定外部模型时按该次指定调用。

归档记录与 `manifest.json` 如实标注实际使用的生图管线或模型，不篡改历史资产的原模型记录。Skill 不复制或保存密钥，不把密钥写进提示词、日志、截图、源码或交付包。

保留原始生成图、完整提示词、选定版本及加工入口。提取透明背景后检查细边、内部孔洞、色边与 alpha；不能以放置品红／棋盘格图片代替实际透明 PNG。资产按项目真实尺寸导出，典型卡面 1000×760、能力图标 256／64 px、战斗记录 88 px 只是当前原版示例，先核实引用合同。

有 alpha 不等于已得到干净主体：在深、浅底色上检查外缘低透明度雾光。清理或反色后复看细指、触角和拖尾，避免全图高阈值把有效细部削掉；轮廓已确认的配色修改可据原轮廓约束 alpha，再检查新颜色和边缘是否仍贴合。

## 场景、火堆与地图

- 战斗背景遵循项目 `docs/background-art-guidelines.md` 与 `sts2-background-art`：**无线哑光 2–3 阶水粉概括画风**（禁止黑描边与过度写实细噪）、非对称纵深、墙基／柱脚／树根经雾气自然收在 `y = 46%..50%`（无尺子直切线）、**100% 纯平齐地原创地板**（具备原版柔和雾面底色与贴地低对比透视节奏，零台阶断层／零亮面泥潭，严禁复用原版蔓生方砖／荣耀多边形石板／虫巢六角砖／幽港木栈道，各房材质独立）及底沿 `y >= 88%..90%` 极暗前景框。
- 站位与 UI 安全预算：4 人后排 `Y = 620px`、1 人／前排 `Y = 740px` 稳踩地板；优先抬正背景地平线而不靠硬压玩家下移补救，所有血条底边保持 `<= 840px` 以避开手牌（`~860px`）、底沿前景与结束回合按钮。既有场景仅地板不合规时，锁死已验收的上半景与底沿只替换地板带。
- 深处新区域地板使用新生成原创资产，场景变化体现不同空间和材质，不只改同一图的色相；等比裁切导出（严禁纵向压扁），动态水面层仅遮罩实画水域。
- 鱼类遭遇沿用已确认的河湾洞穴；墓潮蛞蝓使用地下暗靛潮汐蓄水拱室（不用木栈道）；火堆有独立场景，座位按原人物坐姿、脚／臀接触点和 FlipX 对齐，保留原生休息灯光行为。
- 大地图石板贴图要自然连续；检查重复铺设、缩放与路线／节点的识别度。用户选择退回的版本按最新选择采用，不把“更精细”当成自动更优。
- 事件插画的完整渐暗规则见 [事件规范](events.md) 与项目的 `docs/event-art-guidelines.md`。

## 自审闭环

将最终图与原版同类图并看，检查轮廓、比例、明暗分块、色彩、纹理密度和小尺寸识别。再在实际资源使用场景检查卡框裁切、界面遮挡、脚底／座位接触和前景层次。低多边形拼面、写实材质或过亮特效破坏画风时，针对问题改提示词或回炉，并重新看最终版。

项目示例：`docs/archive/cavegod-ui-art-20261005.md`、`docs/archive/COLLISION_CARD_STYLE_AUDIT_V109.md`、`design/image_generation_preferences.md`。其中旧版本尺寸和色板分析属于该类资产，不是跨类别统一参数。
